このサイトについて

この Python 研修は、JPMorgan のビジネスアナリストとトレーダー、および一部のクライアントを対象としています。

日本語版について: このリポジトリは、jpmorganchase/python-training の日本語版です。単なる翻訳ではなく、翻訳を基礎に、次の増補と修正を行っています。ライセンスは原典と同じ Apache 2.0 です。

  • 翻訳と文体: 全章を翻訳し、直訳調でない自然な日本語に全面リスタイルしています
  • 補足解説: 原文で説明が不足している箇所に、日本語版独自の解説を追加しています（第7・8・9章）
  • 追加実装: 第8章に、SEC EDGAR（APIキー不要）で計算する節と計算の内訳の可視化、第9章には、原文にコードしかなかった箇所への説明と追加のコードを加え、章として組み立てています
  • 修正: 第4章の原文が使う CoinDesk の API は提供が終了していたため、原文のコードは実行できない記録として残し、代替の API で動く経路を追加しています
  • 用語解説: サイト版では各ページの下部に用語解説（金融とプログラムの両分野）を付け、本文中の用語をクリックすると解説に飛べます

独自の補足・追加・修正には、すべて「日本語版独自」と明記し、原文の内容と区別しています。第6章は、原典自体が未実装のプレースホルダ（空のコードセルのみ）のため、日本語版でも未実装です。

概要

このコースは、Python での数値計算とデータ可視化の入門です。コンピュータサイエンスやプログラミングの網羅的なコースではありません。ねらいは、複雑に見える題材でも、プログラミングの専門教育を受けていない人が取り組めることを、実例を通して示すことです。

研修は対面形式で、J.P. Morgan のテクノロジストとトレーダーが講師を務めます。機関投資家のお客様で関心のある方は、J.P. Morgan の担当チームへお問い合わせください。

章一覧

  1. 科学計算のためのベストプラクティス — 開発環境と読みやすいコードの作法（Git、テスト、スタイル）
  2. Jupyter 入門 — Python の基礎とノートブックの使い方
  3. 例1：ストラドルの価格計算 — オプションの価格を近似式とモンテカルロ法で計算する
  4. 例2：ファイルを扱う — OpenFlights の路線データを pandas で読み込み、集計する
  5. Web API からのデータ取得 — API の呼び出しと JSON の整形（日本語版で API 提供終了に対応済み）
  6. Web サイトからデータを取得する — read_html と BeautifulSoup によるスクレイピング
  7. 金融データの利用 — 原典でも未実装のプレースホルダ
  8. グラフ描画の応用：matplotlib の先へ — ボラティリティ・サーフェスなど、描画ライブラリの応用
  9. 金融データを使う例 #1：アルトマンZスコア（ダブルプライム）の計算 — 信用リスクのモデル実装（日本語版で SEC EDGAR 版を追加）
  10. 3次元プロット — 米国債イールドカーブの3次元可視化（日本語版で章として組み立て）

About (English)

This is a Japanese edition of JPMorgan's python-training — translated and expanded. It teaches Python for numerical computing and data visualization with Jupyter notebooks: best practices and Git, Python basics, options pricing (straddle, Monte Carlo), pandas with OpenFlights data, web APIs and JSON, web scraping with BeautifulSoup, advanced plotting and volatility surfaces, the Altman Z'' credit-risk model (with an added keyless SEC EDGAR implementation), and 3D plotting of the US Treasury yield curve. The website edition adds a per-chapter glossary covering both finance and programming terms. Licensed under Apache 2.0, same as the original.
