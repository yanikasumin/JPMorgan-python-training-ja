Web API からのデータ取得¶

「Web 2.0」で大きく変わったのは、外部向け API の整備です。開発者は、公開されたデータの上にツールを組み立てられるようになりました。

API の応答は、機械が読みやすい形式で返ってきます。接続の方式も決まっているため、安定してデータを取得できます。

API は数多く公開されています。利用に開発者キーの登録が必要なものもあります。たとえば セントルイス連邦準備銀行の API です。無料で使えるものもあります。たとえば Coindesk の API です。API を探すときは、ProgrammableWeb のディレクトリ が役立ちます。

大いなる力には、大いなる責任が伴います¶

プログラムから Web サイトにアクセスするときも、マナーを守って使いましょう。

ここでは、Coindesk の API でビットコインの日次価格を取得します。Coindesk の API は、他の多くの API と同じく、JSON（JavaScript Object Notation）形式でデータを返します。JSON は、そのまま DataFrame に変換できます。使うライブラリは json と requests です。

注意（日本語版独自）: このあとの原文のコードセルは、CoinDesk の API が終了しているため実行できません。原文の記録として残し、実行対象外（raw セル）に設定してあります。実際に動く取得の流れは、その直後の「修正（日本語版独自）」のセルで代替の API を使ってたどれます。

import datetime import pandas as pd import json import requests coindeskURL = 'https://api.coindesk.com/v1/bpi/historical/close.json?' # API から取得 start = datetime.date(2019, 1 ,1) end = datetime.date(2019, 7, 1) url = f'{coindeskURL}start={start:%Y-%m-%d}&end={end:%Y-%m-%d}' print(f'Hitting this url:{url}') result = requests.get(url) result.content

修正（日本語版独自）: この API は終了しています

原文が使う CoinDesk の Bitcoin Price Index API は、提供が終了しました。ドメイン自体が応答しないため、上のセルは現在は実行できません（2026年11月に確認）。原文のセルは記録として残します。

もう少し詳しく見てみましょう。データ取得で押さえるポイントはいくつかあります。

API ごとに、返ってくるデータの構造は違います。まずブラウザで URL を開いてみると、返ってくる内容がそのまま確認できることが多いです。試してみましょう。

https://api.coindesk.com/v1/bpi/historical/close.json?start=2019-01-01&end=2019-07-01

この URL では、次の結果が返ってきます。

{
    "bpi":
    {
        "2019-01-01":3869.47,
        "2019-01-02":3941.2167,
        ...
    },
    "disclaimer": "This data was produced from the CoinDesk Bitcoin Price Index.",
    "time":
    {
        "updated":"Jul 2, 2019 00:03:00 UTC",
        "updatedISO":"2019-07-02T00:03:00+00:00"
    }
}

bpi、disclaimer、time の3つが、参照できるデータです。ここで主に使うのは bpi です。

データの分け方は API ごとに違います。他の API の例は、後で出てきます。

Python で JSON の中身を見てみます。

jsondata = json.loads(result.content) jsondata

これを pandas の DataFrame に変換します。

pandas には read_json という関数もあります。ただし、JSON の構造によっては使いにくい場合があります。

# disclaimer や time も一緒に読み込まれる data = pd.read_json(result.content) datadata = pd.DataFrame({'Bitcoin Price Index': jsondata['bpi']}) data%matplotlib inline data.plot()

用語解説

この章に出てくる用語の解説です（日本語版独自の付録）。本文中の用語をクリックすると、ここに飛びます。

API
プログラム同士がデータをやり取りするための窓口。決まった形式でリクエストを送ると、機械が読みやすい形でデータが返ってきます。
JSON
データを表すための軽いテキスト形式。キーと値の組で構造を表し、Web API の応答で広く使われます。
エンドポイント
API の個々の窓口となる URL のこと。欲しいデータごとに場所が決まっています。
関数
処理をひとまとめにして名前をつけたもの。入力を渡すと、決まった処理をして結果を返します。
ライブラリ
よく使う機能をまとめて、他のプログラムから呼び出せるようにした部品集。requests や pandas がその例です。
ビットコイン
代表的な暗号資産（仮想通貨）。この章の原文が、価格データの取得例に使っています。
為替レート
2つの通貨の交換比率。USD/JPY なら、1ドルが何円かを示します。
ドメイン
インターネット上の住所にあたる名前（例: api.frankfurter.dev）。DNS という仕組みで、実際の接続先に変換されます。
